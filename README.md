# hhtdiary.github.io

Official website of [HHT Diary](https://hhtdiary.org/): the organization's home, products, vision, roadmap and about pages.
Plain static HTML published as-is by GitHub Pages; the shared header and footer are built by `assets/site.js`.

TripLibre, HHT Diary's first product, has its own site at <https://triplibre.hhtdiary.org/>, published from `docs/` in
[zyang91/TripLibre](https://github.com/zyang91/TripLibre). The pages under `triplibre/` here are only redirect stubs
that keep the old `hhtdiary.org/triplibre/...` links working.
